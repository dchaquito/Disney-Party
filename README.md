# Magical Party · Tablero manual

Tablero de proyección con la imagen original, ocho fichas numeradas de distintos colores y una corona dorada. Todas las piezas se pueden arrastrar libremente con el mouse. Sus posiciones se guardan automáticamente en el navegador de la computadora donde se utiliza.

## Subir a GitHub Pages

1. Crea un repositorio de GitHub.
2. Sube `index.html`, `styles.css`, `app.js` y la carpeta `assets` con `tablero.png`.
3. En **Settings → Pages**, elige **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda.
4. Abre el enlace publicado y proyecta la página. Para ocupar más pantalla, presiona **F11** en tu navegador.

No necesita Firebase ni registro de estudiantes. Las posiciones se guardan solo en ese navegador y no se sincronizan entre computadoras. Si se borra el almacenamiento del navegador, se perderán las posiciones guardadas.
